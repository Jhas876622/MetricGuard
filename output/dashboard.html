About MetricGuard

MetricGuard scans your team's metric definitions, matches them by meaning using sentence embeddings, and flags where the same business concept is computed differently across teams.

This is the silent reason dashboards disagree. A 10-person data team spending ~35% of time reconciling metrics costs approximately $525K/year.

Stack: all-MiniLM-L6-v2 embeddings → cosine similarity → union-find grouping → sqlglot SQL AST parsing → RAG-grounded Claude recommendations.

Add your own metrics: use the ingestion panel at the bottom of this page — CSV, dbt manifest, database connector, or the CLI wizard.

Guided CLI wizard — no coding required
Run the interactive wizard in your terminal. It asks you questions and builds data/metric_definitions.json.
  1. Open a terminal in your MetricGuard folder
    cd /path/to/MetricGuard
  2. Run the wizard
    python src/cli.py
  3. Answer prompts — team name, metric names, SQL, descriptions
    → Your team name: Finance → Metric name: monthly_revenue → SQL: SELECT SUM(amount) FROM orders WHERE status='completed' → Description: Revenue from completed orders only → Time grain [month]: month ✓ Saved. Add another? [Y/n]:
  4. The wizard offers to run the pipeline — or click Re-run pipeline above.
All ingestion methods
📄 CSV
Spreadsheet from any BI tool
python src/ingest.py csv \ --file metrics.csv \ --team "Finance"
⚙️ dbt
Semantic Layer or tagged models
python src/ingest.py dbt \ --manifest target/manifest.json
🗄️ Database
Any SQLAlchemy-compatible DB
python src/ingest.py db \ --url "postgresql://..." \ --team "Data"
📋 JSON
Script or CI pipeline
python src/ingest.py json \ --file my_metrics.json
Connect directly to your data warehouse
Supports Postgres, Snowflake, BigQuery, Redshift, MySQL and any SQLAlchemy database.
  1. Install your database driver
    pip install psycopg2-binary # PostgreSQL pip install snowflake-sqlalchemy # Snowflake pip install sqlalchemy-bigquery # BigQuery pip install pymysql # MySQL
  2. Run with your connection string
    python src/ingest.py db \ --url "postgresql://user:pass@host:5432/db" \ --team "Analytics" \ --query "SELECT metric_name, sql_definition as sql, description, filters, time_grain FROM analytics.metric_registry"
  3. Without --query, MetricGuard auto-discovers views with metric, kpi, or measure in their name.
  4. Run the analysis
    python src/report.py
